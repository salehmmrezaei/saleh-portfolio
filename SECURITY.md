# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature for this repository instead.

When reporting a vulnerability, include:

- A clear description of the issue
- Steps to reproduce it
- The affected component or endpoint
- Any relevant logs or screenshots with secrets removed
- The potential security impact

Please do not include passwords, API keys, tokens, private keys, database credentials, or other secrets in reports.
